# 给学习者、家长和教师

课程目标是让没有编程经验的人理解 Tcl 的核心规则，并能独立完成一个小型自动化脚本。阅读有困难的学习者可由同伴读故事和任务，不要求一开始记住全部英文命令。年龄不是分班标准，以阅读能力和已有经验调整速度。

## 每次 25–40 分钟的活动

1. 3 分钟：讲关卡故事，问“你觉得电脑接下来会做什么”。
2. 5–10 分钟：运行示例，先预测输出，再改一个值。
3. 10–15 分钟：完成挑战。先用提示 1，再考虑提示 2。
4. 5 分钟：解释为什么通过，用一个新输入验证。
5. 2 分钟：导出进度，记录一个仍然不懂的问题。

可把一次活动拆成两次。不设速度排名，鼓励结对讨论、轮换键盘操作；“答错还能再试”是学习机制。

## 四次主题课，也可以拆成八次

| 主题课 | 内容 | 可观察的学习证据 |
| --- | --- | --- |
| 1 | 第 1–5 关 | 能解释 $、{}、[] 的差别，独立修改信标能量 |
| 2 | 第 6–10 关 | 能预测边界条件，筛选新的角色数据 |
| 3 | 第 11–15 关 | 能区分 puts 与 return，处理空列表和小数 |
| 4 | 第 16–20 关 | 能解释工具命令与 Tcl 核心区别，分析不同报告 |

新手通常需要更多课时。20 关标注时间合计约 4 小时，讨论、复习和拓展可增加到 6–8 小时。

## 课程验收建议

| 维度 | 比例 | 证据 |
| --- | --- | --- |
| 基础规则理解 | 25% | 用自己的话解释括号和变量替换；现场改写示例 |
| 小任务实现 | 25% | 挑战代码及不同输入的结果 |
| 毕业项目 | 30% | analyze 对空报告、全正余量、零余量和负余量的处理 |
| 教学表达与复现 | 20% | 图解、演示、运行说明、学习反思 |

XP 是鼓励性的自学记录，浏览器端内容和答案都可读取，不能作为防作弊考试系统。参考答案应允许查阅，但要求学习者解释并修改一处逻辑。

## VLSI 延伸

第 20 关之后可安排：从文本读取记录 → 检查坏数据 → 输出 CSV → 处理多份报告。真实工具部分需要课程指定的 EDA 环境、许可证和厂商文档。不要把模拟命令作为通用 Calibre API 讲授。
